# NeoToolBoxAI

A compact directory of essential AI tools for professionals.

## Setup Instructions

1.  **Deployment**: Upload the entire `ai-tools` folder to your hosting provider (GitHub Pages, Netlify, InfinityFree, etc.).
2.  **Configuration**: Open `index.html` and replace the following placeholders:
    *   `YOUR-WEBSITE-LINK-HERE`: Replace with your actual domain name.
    *   `PASTE-YOUR-MONETAG-VERIFICATION-CODE-HERE`: Insert your meta tag from Monetag.
    *   `YOUR_ZONE_ID`: Find the ad script at the bottom of the body and replace this with your specific ad zone ID.
3.  **Assets**: If you have a social media banner, name it `banner.jpg` and place it in the `assets/` folder.

## Structure

*   `index.html`: Main structure and content.
*   `css/styles.css`: Visual styling and animations.
*   `js/main.js`: Logic for search bar and scroll animations.
*   `assets/`: Folder for images (favicons, og:image).
